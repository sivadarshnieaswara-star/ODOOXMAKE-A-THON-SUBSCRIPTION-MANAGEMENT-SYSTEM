# Plan 03-01: Admin Tax Rules & Discount Evaluation Engine

## Goal
Implement the configuration and automated evaluation services for Taxes and Discounts. Discounts must support both whole-subscription discounts and product-specific discounts, enforce minimum purchase/quantity criteria, and track usage counters to prevent over-redemption.

## Mathematical Formulation
1. **Discount Evaluation**:
   - For rule $R$ with target `subscription`:
     - Applies if $\text{subtotal} \ge R.\text{min\_purchase}$ AND $\sum \text{qty} \ge R.\text{min\_quantity}$.
     - If $R.\text{discount\_type} == \text{'percentage'}$: $\text{discount} = \frac{\text{subtotal} \times R.\text{value}}{100.0}$.
     - If $R.\text{discount\_type} == \text{'fixed'}$: $\text{discount} = \min(R.\text{value}, \text{subtotal})$.
   - For rule $R$ with target `product` (product ID $P$):
     - Applies if $\sum_{i \in \text{lines}(P)} \text{qty}_i \ge R.\text{min\_quantity}$ AND $\text{subtotal}(P) \ge R.\text{min\_purchase}$.
     - Discount calculated solely on $P$'s subtotal.
2. **Tax Computation with Discounts**:
   - Taxable Subtotal = $\max(0.0, \text{subtotal} - \text{discount})$.
   - For each line $i$: $\text{effective\_line\_subtotal}_i = \text{line\_subtotal}_i - \left(\frac{\text{line\_subtotal}_i}{\text{subtotal}} \times \text{discount}\right)$.
   - $\text{line\_tax}_i = \text{round}\left(\frac{\text{effective\_line\_subtotal}_i \times \text{tax\_rate}_i}{100.0}, 2\right)$.
   - $\text{Total Amount} = \text{Taxable Subtotal} + \sum \text{line\_tax}_i$.

## Tasks

### Task 1: Tax Rules API & Calculation Service
- **Files**: `backend/app/services/tax_service.py`, `backend/app/routers/tax_router.py`, `backend/app/main.py`
- **Action**:
  - `GET /api/taxes`: List active tax rules (`require_staff_or_admin`).
  - `POST /api/taxes`: Create tax rule (`require_admin`).
  - `PUT /api/taxes/{id}`: Update tax rate or default flag (`require_admin`).
- **Verify**:
  ```bash
  uv run python -c "from backend.app.services.tax_service import TaxService; print('TAX_SERVICE_OK')"
  ```

### Task 2: Discount Rules API & Automatic Evaluation Engine
- **Files**: `backend/app/services/discount_service.py`, `backend/app/routers/discount_router.py`, `backend/app/main.py`
- **Action**:
  - `GET /api/discounts`: List discount rules with current vs max usage counters (`require_staff_or_admin`).
  - `POST /api/discounts`: Create discount rule strictly guarded by `require_admin`.
  - `PUT /api/discounts/{id}`: Modify or deactivate discount rule (`require_admin`).
  - Implement `DiscountService.evaluate_best_discount`: selects greatest valid discount candidate, checking dates, minimum quantity/purchase, and usage limit.
  - Implement `DiscountService.consume_discount`: increments `current_uses` and deactivates rule when `current_uses >= max_uses`.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.services.discount_service import DiscountService; print('DISCOUNT_SERVICE_OK')"
  ```

### Task 3: Test Suite for Tax & Discount Mechanics
- **Files**: `backend/tests/test_phase3_discounts.py`

- **Verify**:
