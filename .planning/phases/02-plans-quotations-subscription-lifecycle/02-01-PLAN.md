# Plan 02-01: Recurring Plans & Quotation Templates Engine

## Goal
Implement full CRUD endpoints and business logic for Subscription Plans (including multi-frequency intervals and lifecycle policies decided plan by plan) and Quotation Templates (enabling sales reps to generate offers with preset product lines and validity durations).

## Domain Logic & Mathematical Specifications
1. **Plan Billing Intervals**:
   - `daily`: $+1$ day
   - `weekly`: $+7$ days
   - `monthly`: $+1$ calendar month (`dateutil.relativedelta.relativedelta(months=1)`)
   - `yearly`: $+1$ calendar year (`dateutil.relativedelta.relativedelta(years=1)`)
2. **Plan Policy Governance**:
   - `auto_close_on_expiry`: If True, billing runner auto-transitions expired subscriptions to `closed`.
   - `allow_early_close`: If False, premature cancellation before `expiry_date` is blocked.
   - `allow_pause`: If False, pausing an active subscription is rejected with HTTP 400.
   - `allow_renewal`: If False, renewing a closed subscription is rejected with HTTP 400.
3. **Quotation Template Expiry**:
   - $\text{expiry\_date} = \text{start\_date} + \text{validity\_days}$

## Tasks

### Task 1: Plan Management API & Lifecycle Policy Controls
- **Files**: `backend/app/routers/plan_router.py`, `backend/app/main.py`
- **Endpoints**:
  - `GET /api/plans`: List active plans (Public/Authenticated).
  - `POST /api/plans`: Create plan with cost, frequency, min_quantity, date window, and lifecycle flags (`require_admin`).
  - `GET /api/plans/{id}`: Retrieve detailed plan specification.
  - `PUT /api/plans/{id}`: Update plan details and policy flags (`require_admin`).
  - `DELETE /api/plans/{id}`: Soft-delete/deactivate plan (`require_admin`).
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.plan_router import router; print('PLAN_ROUTER_OK')"
  ```

### Task 2: Quotation Template API & Auto-Expansion Engine
- **Files**: `backend/app/routers/template_router.py`, `backend/app/services/subscription_service.py`, `backend/app/main.py`
- **Endpoints**:
  - `GET /api/templates`: List quotation templates (`require_staff_or_admin`).
  - `POST /api/templates`: Create template with pre-filled product lines and validity days (`require_staff_or_admin`).
  - `POST /api/templates/{id}/instantiate`: Instantiates a new Draft subscription populated with customer ID, plan ID, lines, and calculated expiry date.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.template_router import router; print('TEMPLATE_ROUTER_OK')"
  ```
