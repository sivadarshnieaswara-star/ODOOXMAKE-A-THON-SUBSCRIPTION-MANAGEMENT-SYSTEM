# Plan 04-02: Customer Self-Service Portal & High-Speed Executive Finance Analytics (<2s SLA)

## Goal
Implement the high-performance Executive Finance Analytics service (<2s response SLA) calculating MRR, ARR, cash collection, and accounts receivable, alongside a self-service Customer Portal and responsive web interface inspired by Odoo's design aesthetic.

## Metric Formulations
1. **Active Subscriptions**:
   - Count of all records where `Subscription.status == 'active'`.
2. **Monthly Recurring Revenue (MRR)**:
   - For each active subscription $S$ with monthly cost $C$:
     - If frequency == `daily`: $C \times 30$
     - If frequency == `weekly`: $C \times 4.333$
     - If frequency == `monthly`: $C$
     - If frequency == `yearly`: $\frac{C}{12.0}$
   - $\text{MRR} = \sum_{S \in \text{Active}} \text{Normalized Monthly Amount}(S)$
3. **Annual Recurring Revenue (ARR)**:
   - $\text{ARR} = \text{MRR} \times 12$
4. **Total Revenue Collected**:
   - $\sum \text{Payment.amount}$
5. **Total Outstanding Balance**:
   - $\sum \text{Invoice.balance\_due}$ for all invoices where `status == 'confirmed'`
6. **Query Speed SLA**:
   - Target response time $< 2.0$ seconds (benchmarked with query optimization and indexed lookups).

  - Implement `AnalyticsService.get_financial_overview(db, start_date, end_date, plan_id)`:

    - Benchmarks execution time using `time.perf_counter()`.
    - Returns JSON: `active_subscriptions_count`, `mrr`, `arr`, `total_revenue_collected`, `total_outstanding_amount`, `overdue_invoices_count`, `overdue_amount`, `response_time_ms`.
