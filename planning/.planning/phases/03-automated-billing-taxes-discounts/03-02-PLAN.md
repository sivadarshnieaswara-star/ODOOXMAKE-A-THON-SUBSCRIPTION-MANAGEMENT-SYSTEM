# Plan 03-02: Automated Bulk Recurring Billing Engine & Invoice Lifecycle

## Goal
Implement the recurring billing engine that executes bulk billing across hundreds of active subscriptions, guarantees idempotency against double-billing, tracks billing dates, and manages the full invoice lifecycle with printable output.

## Idempotency & Recurrence Mechanics
1. **Billing Condition**:
   - Query: `Subscription.status == 'active'` AND `Subscription.next_billing_date <= target_date`.
2. **Double-Billing Prevention**:
   - Check A: `subscription.last_billing_date == target_date` (returns immediately with skip notice).
   - Check B: Query existing `Invoice` where `subscription_id == S.id` AND `issue_date == target_date` AND `status != 'cancelled'`. If exists, returns existing invoice without creating duplicate.
3. **Billing Cycle Advancement**:
   - `subscription.last_billing_date = target_date`
   - `subscription.next_billing_date = calculate_next_billing_date(target_date, subscription.plan.billing_frequency)`
4. **Auto-Closure on Expiry**:
   - If `subscription.expiry_date < target_date` and `plan.auto_close_on_expiry == True`:
     - Transition `subscription.status = 'closed'` and skip billing.

## Tasks

### Task 1: Billing Engine Implementation
- **Files**: `backend/app/services/billing_service.py`
- **Action**:
  - Implement `generate_invoice_number(db)` returning `INV-{count:05d}`.
  - Implement `generate_invoice_for_subscription(db, subscription, billing_date, force)`:
    - Evaluates subtotal, discounts via `DiscountService`, and taxes via `TaxService`.
    - Creates `Invoice` and `InvoiceLine` records.
    - Sets initial `status = InvoiceStatus.DRAFT` and `balance_due = total_amount`.
    - Advances subscription billing cycle.
  - Implement `run_bulk_recurring_billing(db, target_date)`:
    - Iterates over all due subscriptions.
    - Returns JSON summary: `total_due_found`, `invoices_generated_count`, `skipped_count`, and invoice details.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.services.billing_service import BillingService; print('BILLING_SERVICE_OK')"
  ```

### Task 2: Invoice Management Router & Printable Template
- **Files**: `backend/app/routers/invoice_router.py`, `frontend/templates/invoice_print.html`, `backend/app/main.py`
- **Endpoints**:
  - `GET /api/invoices`: List invoices filterable by status, customer, date range (`require_staff_or_admin` or customer-scoped).
  - `GET /api/invoices/{id}`: Detailed invoice view with lines, taxes, discount, and balance.
  - `POST /api/invoices/{id}/status`: Transition status: `draft` -> `confirmed` -> `cancelled`.
  - `POST /api/invoices/{id}/send`: Simulates email delivery, records `sent_at` timestamp.
  - `GET /api/invoices/{id}/print`: Returns clean, printable HTML document styled with Brightloop branding ready for browser print / PDF export.
  - `POST /api/billing/run-recurring`: Trigger bulk recurring billing run for today or specified date (`require_staff_or_admin`).
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.invoice_router import router; print('INVOICE_ROUTER_OK')"
  ```
