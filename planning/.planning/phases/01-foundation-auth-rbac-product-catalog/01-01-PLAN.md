# Plan 01-01: Foundation, Database Models, Schemas & Auth with Strict Password Policy

## Goal
Implement the core SQLite database connection, SQLAlchemy ORM models, Pydantic schemas, password validation adhering strictly to the Brightloop Make-A-Thon requirements, JWT authentication, RBAC guards, secure password reset, and default admin bootstrap.

## Tasks

### Task 1: Database Setup, ORM Models & Admin Bootstrap
- **Files**: `backend/app/config.py`, `backend/app/database.py`, `backend/app/models.py`, `backend/seed_data.py`
- **Action**:
  - Define relational schema: `User`, `Product`, `ProductVariant`, `Plan`, `QuotationTemplate`, `Subscription`, `SubscriptionLine`, `TaxRule`, `DiscountRule`, `Invoice`, `InvoiceLine`, `Payment`, and `AuditLog`.
  - Add `@property def effective_price(self)` on `ProductVariant` returning `self.product.sales_price + self.surcharge`.
  - Create `backend/seed_data.py` with an idempotent function `bootstrap_admin(db)` that ensures `admin@brightloop.com` exists with role `admin` and compliant password `BrightloopAdmin#2026`.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.database import engine, Base, SessionLocal; from backend.seed_data import bootstrap_admin; Base.metadata.create_all(bind=engine); db = SessionLocal(); bootstrap_admin(db); print('BOOTSTRAP_OK')"
  ```

### Task 2: Pydantic Validation Schemas & Strict Password Policy
- **Files**: `backend/app/schemas.py`, `backend/app/auth.py`
- **Action**:
  - Implement `validate_password_strength(password)` strictly enforcing:
    1. `len(password) > 8` (at least 9 chars)
    2. At least one uppercase character `[A-Z]`
    3. At least one lowercase character `[a-z]`
    4. At least one special character `[^A-Za-z0-9]`
  - Implement `hash_password`, `verify_password` (using `secrets.compare_digest`), `create_access_token`, and RBAC dependencies `require_admin` and `require_staff_or_admin`.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.auth import validate_password_strength; from fastapi import HTTPException; [exec('try:\n validate_password_strength(p)\n assert ok\nexcept HTTPException:\n assert not ok') for p, ok in [('weak', False), ('NoSpecial1', False), ('nosmall1!', False), ('NOUPPER1!', False), ('ValidPass123!', True)]]; print('PASSWORD_VALIDATOR_OK')"
  ```

### Task 3: Authentication & Password Reset Router with Replay Protection
- **Files**: `backend/app/routers/auth_router.py`, `backend/app/main.py`
- **Action**:
  - `POST /api/auth/register`: Check duplicate email first and return 400 if already exists. Validate password strength. Create customer account.
  - `POST /api/auth/login`: Authenticate and return JWT access token with user details.
  - `GET /api/auth/me`: Return current user details.
  - `POST /api/auth/forgot-password`: Generate secure token with 1-hour expiry, save to user record, return simulated reset token.
  - `POST /api/auth/reset-password`:
    - Verify token is valid and `reset_token_expiry > datetime.utcnow()`.
    - Enforce `validate_password_strength(data.new_password)`.
    - Update user password hash/salt and set `reset_token = None` and `reset_token_expiry = None` to block replay attacks.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.auth_router import router; print('AUTH_ROUTER_LOADED_OK')"
  ```
