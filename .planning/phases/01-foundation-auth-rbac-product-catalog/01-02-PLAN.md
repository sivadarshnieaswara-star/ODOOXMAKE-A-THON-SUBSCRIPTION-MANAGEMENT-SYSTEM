# Plan 01-02: Product & Variant Catalog APIs, Admin Staff Provisioning & Verification Suite

## Goal
Implement the REST endpoints for product and variant management (Admin-only for mutation), admin-only staff provisioning with password validation, and an automated verification test suite verifying all Phase 1 constraints.

## Tasks

### Task 1: Admin Staff Provisioning API with Password Policy Check
- **Files**: `backend/app/routers/staff_router.py`, `backend/app/main.py`
- **Action**:
  - Implement `POST /api/staff` restricted strictly to `require_admin`.
  - Validate `staff_in.password` using `validate_password_strength(staff_in.password)`.
  - Verify email uniqueness; if already exists, return 400 Bad Request.
  - Implement `GET /api/staff` restricted to `require_admin` returning staff accounts.
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.staff_router import router; print('STAFF_ROUTER_LOADED_OK')"
  ```

### Task 2: Product & Variant Catalog Router with Admin RBAC Enforcement
- **Files**: `backend/app/routers/product_router.py`, `backend/app/main.py`
- **Action**:
  - `GET /api/products`: Accessible to authenticated users (admin, staff, customer) to view active catalog.
  - `POST /api/products`: Restricted strictly to `require_admin`. Create product with base price, cost price, and optional initial variants.
  - `GET /api/products/{id}`: Return single product with variants and computed `effective_price`.
  - `POST /api/products/{id}/variants`: Restricted strictly to `require_admin`. Add variant option with surcharge (e.g. "Brand: Odoo" with surcharge `560.0`).
- **Verify**:
  ```bash
  uv run python -c "from backend.app.routers.product_router import router; print('PRODUCT_ROUTER_LOADED_OK')"
  ```

### Task 3: Comprehensive Test Suite for Phase 1
- **Files**: `backend/tests/test_phase1.py`
- **Action**: Create automated test cases using `pytest` and `httpx.AsyncClient` or `TestClient`:
  - Test registration password validation (>8 chars, uppercase, lowercase, special char).
  - Test duplicate email registration returning 400.
  - Test login and JWT generation.
  - Test RBAC: customer blocked from staff endpoints (403); staff blocked from creating staff (403); staff blocked from creating products (403); only admin allowed.
  - Test password reset flow: request token, test expired/invalid token handling, reset password with strong password, verify token cannot be reused.
  - Test product and variant creation with surcharge calculation (`sales_price + surcharge`).
- **Verify**:
  ```bash
  uv run pytest backend/tests/test_phase1.py -v
  ```
